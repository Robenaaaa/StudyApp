# 유령집사의 공부방 (개인용)

원본 앱 컨셉 + 요청하신 기능(완성률/형광펜 효과, 코인 리워드, 시간표+알람, 반복 할일)을 담은
개인용 웹 앱입니다. `index.html`, `style.css`, `app.js` 3개 파일로만 되어 있어요.

## 1. 지금 바로 스마트폰에서 테스트하기

**중요:** 파일을 그냥 더블클릭(`file://`)해서 열면 로컬 저장(할일/코인 데이터)은 되지만,
**알림(🔔) 기능은 브라우저 보안 정책상 작동하지 않을 수 있어요.**
아래처럼 로컬 서버로 띄워서 테스트하는 걸 추천해요.

### 방법 A: PC와 같은 와이파이로 테스트 (추천)
1. PC 터미널에서 이 폴더로 이동 후:
   ```
   python3 -m http.server 8000
   ```
2. PC의 IP 주소 확인 (Windows: `ipconfig`, Mac: `ifconfig` 또는 시스템 설정 > 네트워크)
3. 스마트폰이 **같은 와이파이**에 연결되어 있는지 확인
4. 스마트폰 크롬 브라우저에서 `http://[PC의 IP]:8000` 접속 (예: `http://192.168.0.15:8000`)
5. 크롬 메뉴 → "홈 화면에 추가" 하면 아이콘처럼 실행돼요 (PWA)

### 방법 B: 그냥 파일 열기 (간단하지만 알림 제한)
`index.html`을 스마트폰으로 옮겨서 파일 앱 → 크롬으로 열기. 할일/코인/타이머는 정상 작동하지만
시간표 알림은 앱을 열어둔 상태에서만 확인 가능해요(토스트 알림으로는 뜸).

## 2. 나중에 진짜 안드로이드 앱(APK)으로 만들기 — Capacitor

PC에 Node.js + Android Studio가 설치되어 있어야 합니다. 순서:

```bash
npm install -g @capacitor/cli
mkdir ghost-study-native && cd ghost-study-native
npm init -y
npm install @capacitor/core @capacitor/android
npx cap init "유령집사의 공부방" "com.myapp.ghoststudy" --web-dir=www
```

1. 지금 만든 `index.html`, `style.css`, `app.js`를 새로 생긴 `www` 폴더 안에 그대로 복사
2. 안드로이드 프로젝트 추가:
   ```bash
   npx cap add android
   npx cap copy
   npx cap open android
   ```
3. Android Studio가 열리면 실행(▶) 버튼으로 준비된 테스트폰(USB 디버깅 켜고 연결)에 바로 설치 가능

### 진짜 백그라운드 알람이 필요하면
지금 버전의 알림은 앱이 켜져 있을 때만 정확히 동작해요. 앱을 꺼도 시간표 알람이 울리게 하려면
Capacitor의 `@capacitor/local-notifications` 플러그인을 추가로 설치해서
`app.js`의 `fireAlarm` 부분을 이 플러그인 API로 바꿔야 해요. 이 단계는 실제 앱으로 전환하는
시점에 이어서 도와드릴게요.

## 3. 데이터는 어디에 저장되나요?
브라우저의 `localStorage`에 저장돼요 (기기/브라우저 안에만 있음, 서버 전송 없음).
브라우저 데이터를 지우면 기록도 사라지니, 나중에 앱으로 전환할 때 데이터 내보내기/가져오기
기능이 필요하면 말씀해주세요.

## 4. 포함된 기능
- 뽀모도로(25/5분) & 기본(스톱워치) 타이머, 캐릭터/방 꾸미기 홈 화면
- 할일: 오늘의 완성률 바 + 체크 시 형광펜 효과, 당일만 체크 가능, 반복 요일 설정(월/목 등)
- 코인: 할일 완료 → **다음날** 코인 자동 적립 → 상점에서 유령 캐릭터/방 아이템 구매·착용
- 시간표: 요일별 수업 등록 + 알람 켜기/끄기 (알림 권한 요청 버튼 포함)
- 통계: 오늘/이번주 공부시간, 완성률 스트릭, 최근 7일 그래프
